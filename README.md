# Азын хүрд

300 оролцогчид зориулсан сугалаа. Алчуур, цацдаг үнэртүүлэгч, салоны хөөс цэвэрлэгч тус бүр 30, хонжворгүй 210. Бензиний талон болон бэлгийн багц 0.

## Netlify-д холбох

GitHub repository-г Netlify-д import хийхэд `netlify.toml` статик файлууд болон `/api/draw` function-ийг тохируулна. `@netlify/database`-г Netlify build суулгаж, боломжит төлөвлөгөөнд database үүсгэн, `netlify/database/migrations` доторх SQL-ийг хэрэглэнэ. Database нь Netlify-ийн кредит ашиглах боломжтой. Deploy-ийн log болон database үүссэн эсэхийг шалгаарай.

Production database-г туршилтаар бүү эргүүл: бодит эрх зарцуулагдана. Preview deploy-ийн тусдаа database дээр туршсаны дараа production-д зориулсан QR кодыг түгээнэ. Мэдээллийн сан автоматаар дахин эхлэхгүй тул бодит арга хэмжээг эхлэхээс өмнө үлдэгдлийг шалгах хэрэгтэй.

Нэг хөтөч дэх давтан хүсэлт нэг үр дүн авна. Өөр хөтөч, төхөөрөмж эсвэл хадгалсан мэдээллээ цэвэрлэсэн хүнийг ижил хүн гэж танихгүй. Нэг хүн нэг л удаа оролцохыг бүрэн хангах бол нэг удаагийн код эсвэл өөр таних арга нэмж хэрэгтэй.

## Компьютерт ажиллуулах

Node.js 24+ суусан үед `npm.cmd run dev`, дараа нь http://localhost:3201/ хаягаар нээнэ. Локал сервер `draws.sqlite` файлд өгөгдлөө тусад нь хадгалдаг; Netlify-ийн database-тэй нэг сан биш. `npm.cmd test` нь локал тооллого болон Netlify хүсэлтийн боловсруулалтыг шалгана.
